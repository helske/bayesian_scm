# More info on StanCon2026 poster "bscm: an R package for Bayesian synthetic control models for panel data causal inference"

## Software

The `bscm` R package is available on [CRAN](https://CRAN.R-project.org/package=bscm) and [GitHub](https://github.com/helske/bscm).

Bayesian synthetic control for causal inference with uncertainty quantification.
